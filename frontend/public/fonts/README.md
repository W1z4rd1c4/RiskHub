# frontend/public/fonts

## Purpose

Public location for the license notices distributed with the frontend's
self-hosted fonts. The font binaries are maintained in
[`frontend/src/assets/fonts/files/`](../../src/assets/fonts/files/).

## Contents

- `licenses/` — license notices for the bundled fonts

## Notes

The source [`fonts.css`](../../src/assets/fonts/fonts.css) declares the bundled
font faces, and [`manifest.json`](../../src/assets/fonts/manifest.json) records
their source paths and checksums. Keep these license notices aligned with those
production font assets when adding or replacing a font family.
