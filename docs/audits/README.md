## Notes

- Audits are historical records and may be superseded by later remediation or
  follow-up reviews.
- Current work status belongs in GitHub Issues, pull requests, and Projects.
- Session transcripts and mutable implementation logs are not durable audit
  records; preserve decisions and evidence instead.
- Keep this README updated when audit records or dispositions change.
