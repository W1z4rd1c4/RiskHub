# docs/agents

Operating references for automated agents working in this repository. The agent
execution protocol itself lives in the sibling `docs/agent/README.md`; the pages
here document the supporting vocabularies and workflows agents rely on.

## Contents

- [`domain.md`](./domain.md) — single-context domain docs: where the ADRs and the `CONTEXT.md` glossary live.
- [`issue-tracker.md`](./issue-tracker.md) — issues are tracked as GitHub issues via the `gh` CLI (external PRs are not a triage surface).
- [`triage-labels.md`](./triage-labels.md) — the canonical five-role triage-label vocabulary.
