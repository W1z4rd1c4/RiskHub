## Product Arc

RiskHub’s versioned roadmap developed through these broad capability families:

1. foundation, authentication, control/risk catalogs, and dashboards;
2. reporting, automated testing, risk appetite, KRI management, and RBAC;
3. notifications, historization, compliance governance, issues, assessments,
   user settings, deployment, and vendor risk;
4. localization, Risk Hub configuration, audits, remediation waves, E2E data,
   archive/restore behavior, maintainability, and architecture deepening;
5. production installation and readiness hardening.

## Change Rule

Add roadmap intent here only when it is useful across commits. Put executable
scope, ownership, acceptance criteria, dependencies, and status in the live
GitHub work item. A merged delivery change may update this snapshot to record the
result, but must not turn this file back into a parallel live tracker.
