# Phase Archives Index

This folder contains historical phase plans and summaries.

## How To Navigate

1. Use folder names to locate the phase/milestone segment.
2. Treat completed `*-PLAN.md` and `*-SUMMARY.md` files as immutable historical
   records.
3. Use [`.planning/STATE.md`](../STATE.md) and
   [`.planning/ROADMAP.md`](../ROADMAP.md) only as versioned technical context
   for the commit that contains them.
4. Confirm live scope, assignment, priority, blocking, review state, and closure
   in the applicable GitHub Issue, pull request, or Project item before treating
   any phase plan as active.

See
[`docs/DOCUMENTATION_OWNERSHIP.md`](../../docs/DOCUMENTATION_OWNERSHIP.md) for
the authority and conflict-resolution contract.

## Archival Notes

- Older phase documents may include legacy absolute links (including
  `file:///...`) from earlier repository layouts.
- Legacy link mapping and path normalization reference:
  - [`docs/reference/LEGACY_PATH_MAP.md`](../../docs/reference/LEGACY_PATH_MAP.md)
- Archive documents are indexed for discoverability; their historical bodies
  are not bulk rewritten.
